# Paper graph exports

Use the files listed in graph_pages.json for the report. Three-model comparisons have a two-model page and a separate third-model page. The original graphs_best_accuracy / graphs_sparse files retain all models as overview figures. Individual-model files are also supplied.

PDF and SVG exports are vector graphics. PNG previews are 300 dpi. Figures are 6.7 inches wide (about 17 cm); use width=\linewidth in an A4 report. Split two-model figures are 8.95 inches high; single-model figures are 4.85 inches high. Node labels are 9.5 pt at native width. B/M/T denotes bottom/middle/top floor; P denotes a perimeter zone. Paths are not weighted by conductance. Direct shared-wall colouring retains the saved adjacency classification.

This update changes presentation only. No fits, topology choices, parameters or prediction metrics were modified.
